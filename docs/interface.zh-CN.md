# 工作空间界面

“我的邮箱”使用紧凑顶部导航，主要空间用于邮箱列表。名称、默认地址、收发开关状态、未读数和进入入口按行展示；管理员可直接进入该邮箱的地址与成员管理。数量与未读总数压缩成一行，关联地址按需展开，支持名称/地址搜索、有未读筛选和手动刷新。账号与安全、管理后台继续使用工作空间侧栏，手机端使用顶部导航。

邮箱阅读界面保留原有布局、工具栏和文件夹样式。点击侧栏原有邮箱名称打开切换菜单，菜单显示地址、未读数及当前选中项；底部账号菜单提供个人设置、管理后台和退出入口。移动端继续使用原有抽屉侧栏。

管理后台按用户、邮箱、域名、注册设置和操作记录分区，并通过 URL 参数保留当前分区与邮箱选择。用户列表支持搜索和状态筛选，创建权限、使用额度与账号操作集中在成员设置弹窗。邀请和重置链接使用独立弹窗与复制操作。邮箱管理采用列表与详情两栏，停用和旧目录维护放在次要位置。域名卡片区分当前保存状态和未保存的设置，显式保存。

视觉使用原项目 Kumo 组件及主题色变量，个人区和后台共用页面间距、面板、状态标记和表单规范；新增 CSS 使用专用类名，避免影响邮件阅读、写信和 AI 面板。界面适配手机、键盘操作和减少动态效果设置。

本次仅修改前端，不变更认证、权限、API、数据库或邮件存储。浏览器验收使用本地模拟数据，不发送真实邮件或修改线上用户。
